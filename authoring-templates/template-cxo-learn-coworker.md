# [產品]中的CX Enterprise Coworker

同事是Adobe的對話式AI，與CX Enterprise應用程式（如[產品]）深度整合。 它接受過Adobe最佳作法的訓練，能讓您快速且正確地完成工作，因此您不需要點選多個畫面和工具，而是以簡單的語言描述您想要的內容，例如「[example prompt one]」或「[example prompt tone]」，而Co-worker會規劃工作、在您連線的Adobe應用程式中執行，並顯示結果以供檢閱。

對於[產品]，這表示花在[在產品中執行手動工作]的時間更少，花在檢閱及核准同事產生的內容上的時間則更多。 您在每個步驟都由您控制，而Co-worker處理計畫、執行和後續工作。

## 開始使用同事

同事的新手嗎？ 從這裡開始，全面瞭解如何協助您在[產品]和其他CX Enterprise應用程式中更有效率地工作。
