# 文件更新 {#documentation-updates}

使用此頁面尋找CX Enterprise Coworker檔案中的新內容及大幅更新內容。 更新會依月份列出，最新的排在前。 如需團隊同事的產品變更，請參閱[團隊同事發行說明](../coworker-for-teams/release-notes.md)。

## 2026年11月 {#nov-2026}

**2026年11月10日**

* 已更新： [開始使用同事聊天](../chat/ui-guide.md)。 可用性表格現在會列出Customer Journey Analytics B2B edition、Content Analytics和Marketing Campaign Analytics。 三種體驗皆可在沈浸式與產品內提供同事聊天。

**2026年11月4日**

* 更新日期： [詢問有關您內容的問題](../chat/use-cases/data-insights/ask-content-questions.md)。 具有`analyze-content`技能的內容分析現在已普遍可用。

**2026年11月3日**

* 新增： [使用同事](../chat/use-cases/journeys/simulate-journey-using-coworker.md)模擬歷程

**2026年11月2日**

* 更新日期： [CX Enterprise Coworker概觀](../home.md)和[開始使用同事聊天](../chat/ui-guide.md)。 Adobe Analytics現在列為提供同事聊天的應用程式。
* 已更新： [同事聊天工作流程](../chat/use-cases/workflows.md)。 本文現在列出檢查AEM工作流程和探索Dispatcher深入分析的技能。 此外也新增庫存分佈、庫存健康情況、歷程和重複偵測的對象技能，並注意對象建立可支援B2C和B2B對象。
