# 關於同事專案 {#overview}

>[!AVAILABILITY]
>
>同事專案的可用性有限。 請聯絡您的Adobe客戶代表，瞭解更多如何參與的資訊。

同事專案是分享的體驗，其中從業人員使用可重複使用的工作流程來完成端對端客戶體驗工作。 工作流程可跨Adobe CX Enterprise和協力廠商應用程式將人員、代理、技能和業務內容整合在一起。 治理和人力決定指導著工作的從頭到尾。

授權的使用者可以建立、發佈和管理專案範本。 從業人員使用範本為業務計畫啟動專案、與團隊合作，以及在核准閘道做出決策。

>[!NOTE]
>
>同事專案和[同事聊天](/help/chat/overview.md)是Adobe CX Enterprise Coworker的模組。 本頁涵蓋「同事專案」。

## 包含的專案範本 {#project-templates}

從常見行銷使用案例的內含範本開始。 每個範本都會提供可重複的工作流程，讓您根據業務需求進行調整。 從這五個範本中選擇，以在「同事專案」中啟動專案。

### 統一的對象和協調的歷程 {#unified-audiences-orchestrated-journeys}

規劃、啟動和衡量整個客戶歷程的B2C行銷活動。 使用Adobe Real-Time CDP建立及啟用對象，並使用Adobe Journey Optimizer透過啟動協調行銷活動。 使用Adobe Customer Journey Analytics瞭解效能。

遵循決策、驗證、核准和測量的可重複流程。 套用您組織的品牌、同意、法律和治理要求。

必要的相容應用程式：Adobe Workfront和Marketo Engage。

### 行銷活動啟動的企業簡報 {#enterprise-brief-campaign-launch}

將B2B行銷活動簡介轉換為電子郵件行銷活動，以準備執行。 在Workfront中管理規劃和共同作業，並在[!DNL Adobe Marketo Engage]中建置和準備行銷活動。

在傳送前完成品質檢查和必要的核准，然後在Workfront中擷取結果。 遵循從規劃到執行和測量的可重複路徑。

必要的相容應用程式： Adobe Journey Optimizer (B2C)、Real-Time CDP和[!DNL Adobe Customer Journey Analytics]。

### 付費媒體行銷活動 {#paid-media-campaign}

透過協調的工作流程，規劃、啟動和最佳化付費媒體促銷活動。 從Workfront中的目標、預算、時機、目的地和預期結果開始。 協調跨Real-Time CDP、[!DNL Adobe GenStudio for Performance Marketing]和[!DNL Adobe Experience Manager Assets]的對象、創意和目標。

發佈前完成驗證並花費授權。 然後檢閱最佳化建議並關閉行銷活動。

必要的相容應用程式： [!DNL Adobe GenStudio for Performance Marketing]、Real-Time CDP、[!DNL Adobe Experience Manager Assets]和Workfront。

### 行銷活動和歷程健康觀察 {#campaign-journey-health-watch}

監視Journey Optimizer中行銷活動和歷程的運作狀況。 在設定的監視視窗中檢閱即時歷程及其關聯的對象。 識別發佈、停止或傳送事件失敗的行銷活動，並檢閱可能的原因和建議的後續步驟。

跨稽核追蹤新發現、未完成或解決的發現。 監視問題而不變更Journey Optimizer。

必要的相容應用程式： Journey Optimizer。

### 實驗績效審查 {#experiment-performance-review}

檢閱實驗效能並決定要採取的行動。 使用Adobe Journey Optimizer和[!DNL Adobe Customer Journey Analytics]中的實驗功能，以一致地評估作用中的實驗。

在定期審查期間擷取發現和決定。 識別獲勝體驗何時準備好前進或表現缺佳的體驗需要採取行動。

必要的相容應用程式：Journey Optimizer和Customer Journey Analytics。

## 專案體驗 {#project-experience}

使用「同事專案」來協調業務目標的工作流程：

* **您目標的工作流程：**&#x200B;設計並部署可協調多個代理程式的工作流程，並具有控管和人工核准閘道。
* **最適化執行：**&#x200B;透過事件、訊號或排程觸發工作。 同事會根據您的目標評估結果，並根據結果調整或觸發動作。
* **Collaboration與核准：**&#x200B;檢閱、核准並在共用專案內採取行動，整個工作流程都有相關人士可以使用的內容。
