# [!DNL Coworker]記憶體：個人化AI以提高工作效率

[!DNL Coworker]記憶體可記憶對您工作最重要的偏好設定、更正內容和工作樣式，協助建立更一致、更有效率且個人化的互動。

「記憶體」可讓同事在不同工作階段之間傳遞選取的資訊，而不是每次您開始新的交談時重複相同的指示，協助您提供更快速且更相關的回應。

>[!VIDEO](https://video.tv.adobe.com/v/3503657/?learn=on&enablevpops)

## 瞭解記憶體

記憶體的設計可在對話中保留有用的資訊，包括：

- 偏好的回應格式
- 工作樣式和通訊偏好設定
- 商業術語
- 專業內容
- 報告預設值和分析偏好設定
- 時區設定

例如，如果您一直偏好簡明的專案要點回應，或對商業物件使用特定的術語，同事可以記住這些偏好設定，並在未來的交談中自動套用。

## 記憶體與交談記錄

記憶體和交談記錄有不同的用途。

### 交談記錄

交談記錄可讓您：

- 返回先前的聊天
- 檢閱先前的討論
- 參考過去的互動

### 記憶

記憶體可讓同事：

- 保留所選的偏好設定
- 套用已儲存的更正
- 個人化未來的互動
- 改善跨工作階段的一致性

記憶體是個人化層，不是每次交談的記錄。

## 記憶體與商務內容

記憶體不應與商務內容混淆。

### 業務情境

企業內容在組織資訊中的同事依據，例如：

- 公司資料
- 原則
- 治理架構
- 連線的企業系統

### 記憶

記憶體主要針對個別使用者及其偏好設定。

它有助於個人化互動，但不會取代組織資料來源、許可權或治理控制項。

## 將偏好設定儲存在記憶體中

儲存資訊最簡單的方法之一，就是在進行交談時清楚說明。

例如：

- 專業角色與責任
- 偏好的通訊樣式
- 報表偏好設定
- 時區資訊
- 常用術語

使用「記住……」等片語 可讓同事識別應保留供未來工作階段使用的偏好設定。

## 實務範例：促銷活動績效報表

影片示範如何使用Customer Journey Analytics簡化記憶體報表工作流程。

在範例中：

1. 使用者要求行銷活動績效報表。
2. Co-worker會識別資料來源和報告元件。
3. 使用者會將偏好的報表設定儲存至記憶體。
4. Co-worker會在未來分析中自動套用這些偏好設定。

因此，後續報表會使用使用者偏好的維度、量度和報表假設來傳送，不需要額外的指示。

## 管理記憶體

使用者仍可控制儲存在記憶體中的資訊。

在&#x200B;**自訂>記憶體**&#x200B;中，使用者可能可以：

- 啟用或停用記憶體
- 檢閱儲存的偏好設定
- 檢查個別的記憶體專案
- 編輯儲存的資訊
- 刪除不再有用的記憶體

可用的控制項可能會依組織設定和管理員啟用的Adobe體驗而有所不同。

## 重要考量

記憶體是為個人化而設計，而不是作為記錄系統。

不要依賴記憶體做為下列專案的授權來源：

- 客戶資料
- 行銷活動績效資料
- 法律要求
- 合規性決定
- 安全性決定

記憶體也不會：

- 授予Adobe產品的存取權
- 提供其他許可權
- 覆寫治理控制項
- 取代組織資料系統

一律遵循組織的治理政策和管理員指引。

## 重點提要

Adobe Co-worker Memory透過在對話中攜帶重要偏好設定和更正內容，有助於減少重複指示，並建立更個人化的AI體驗。

只要記住您想要工作的方式，同事就可以隨著時間而變得日益有用，同時仍能在貴組織建立的治理和安全控制範圍內運作。
