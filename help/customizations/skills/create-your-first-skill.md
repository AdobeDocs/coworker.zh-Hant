# 建立您在同事中的第一個技能

在本影片中，您將會瞭解零售分析人員如何使用同事和Customer Journey Analytics (CJA)，在緊迫的期限內準備高階主管業務績效簡報。
 
分析師不會手動建立報表和詮釋量度，而是與同事合作以：

- 將業務問題對應至可用的KPI
- 驗證報告涵蓋範圍
- 找出可用量度中的差距
- 產生適合執行的報告
- 解讀結果並摘要關鍵發現
- 將分析轉換為可重複使用的技能

結果會產生可重複的工作流程，只需簡單的提示即可依需求執行。

>[!VIDEO](https://video.tv.adobe.com/v/3502341/?captions=chi_hant&learn=on&enablevpops)

## 將分析變成可重複使用的技能

分析師不會儲存單一答案，而是要求Co-worker儲存用來建立分析的方法。

Co-worker會辨識週期性模式、擷取工作流程，並建立可在未來再次執行的可重複使用技能。

## 設定動態時間範圍

由於績效報告每個月都會發生，因此分析人員會設定使用動態日期範圍的技能。 這可讓未來的執行自動分析最相關的報告期間，而不需要手動更新。

## 發佈並調整

分析人員檢閱完產生的技能後，會發佈該技能以供日後使用。 這項技能稍後可以細化，以解決KPI差距或支援隨著報告需求變化的其他業務問題。
