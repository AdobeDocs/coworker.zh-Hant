# 同事外掛程式：其功能、運作方式及安裝方式

此影片介紹外掛程式，並說明它們如何以新功能延伸[!DNL Coworker]。 您將瞭解什麼是外掛程式、其包含哪些元件、外掛程式與技能和MCP伺服器的關係，以及如何從您的工作區安裝、使用和移除外掛程式。

>[!VIDEO](https://video.tv.adobe.com/v/3503666/?captions=chi_hant&learn=on&enablevpops)

## 什麼是外掛程式？

外掛程式是適用於Adobe Co-worker之相關功能的可安裝套件。 將其視為針對特定業務功能或使用案例而設計的現成工具組。

外掛程式可以包括：

- 執行特定工作的專業技能
- 將Co-worker連線到外部Adobe解決方案和服務的MCP伺服器
- 可簡化部署與管理的套件功能

## 瞭解重要概念

影片說明幾個重要元件之間的關係：

| 元件 | 目的 |
|-----------|---------|
| 市集 | 探索到可用外掛程式的目錄 |
| 外掛程式 | 可安裝的功能套件 |
| 技能 | 執行特定工作的可重複使用指令 |
| MCP 伺服器 | 與外部工具及服務的受控連線 |

連線的Adobe解決方案範例包括：

- Adobe Journey Optimizer
- Real-Time CDP
- Adobe Target
- Adobe Workfront

## 檢視已安裝的外掛程式

了解做法：

1. 開啟&#x200B;**自訂**
2. 瀏覽至&#x200B;**外掛程式**
3. 檢閱已安裝的外掛程式套件
4. 檢視外掛程式來源資訊和說明
5. 探索外掛程式的詳細資訊和功能

此影片也會說明為何不同組織之間的外掛程式可用性會因設定、許可權和啟用的功能而異。

## 探索外掛程式功能

瞭解外掛程式如何包含有助於完成常見作業任務的大量技能集合，例如：

- 尋找重複的對象
- 監視Experience Platform資料流健康情況
- 分析客戶資料
- 支援歷程建立和最佳化

## 安裝新的外掛程式

逐步解說會示範如何：

1. 瀏覽可用的市集
2. 尋找外掛程式
3. 檢閱外掛程式詳細資料
4. 安裝外掛程式
5. 讓新功能可在同事中使用

## 在同事中使用外掛程式

安裝後，影片會說明如何在聊天體驗中使用外掛程式。

此範例示範如何建立獎勵會員的忠誠度挑戰，以獎勵購買後的會員。

在執行期間，「同事」可提供下列專案的透明度：

- 使用的技能
- 諮詢的資料來源
- 已執行的查詢
- 結果的產生方式

## 治理與安全性

主要成果是安裝外掛程式不會略過組織治理控制。

同事繼續榮譽：

- 使用者權限
- 存取控制
- 核准需求
- Adobe組織治理原則

安裝外掛程式不會自動授與使用者尚未獲授權使用的產品或動作的存取權。

## 移除外掛程式

影片的最後部分會示範如何在不再需要已安裝的外掛程式時移除該外掛程式。

移除外掛程式也會移除該套件中隨附的功能。

## 主要外賣

外掛程式可封裝相關技能，並將控管連線整合至可安裝的解決方案，讓Co-worker具備擴充能力。 Marketplaces可協助使用者探索外掛程式、執行特定工作的技能，以及MCP伺服器以安全、受管的方式將同事連結至Adobe Experience Cloud應用程式和服務。
