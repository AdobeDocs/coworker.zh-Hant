# 同事自訂概觀 {#overview}

自訂功能可讓您擴充及個人化同事，以符合團隊的運作方式。 使用技能標準化可重複的工作流程、整合功能將Co-worker連線至您的其他系統、外掛程式將相關功能捆綁至可安裝的套件，以及記憶體，在交談中攜帶您的偏好設定和工作風格。
