# Adobe CX Enterprise Coworker Chat概觀 {#overview}

同事聊天是讓客戶體驗工作完成的對話式介面。 您以簡單的語言描述目標（例如「建立春季瑜伽促銷活動的對象」或「告訴我為什麼這個對象上週會收縮」），Co-worker Chat會規劃工作、在Adobe和連線系統上執行、驗證結果，以及將完成的工作交還給您核准。

價值：過去跨越多個熒幕、團隊和天數的工作，現在只需幾分鐘即可在一個交談中進行。 您可以透過檢閱和核准來委派結果並維持控制；同事聊天會執行步驟、在此過程中從錯誤中恢復，並隨著瞭解您團隊的工作方式而變得更清晰。

>[!AVAILABILITY]
>
>同事聊天功能現已正式推出。 功能與連線的應用程式持續擴展。 請檢視可用的技能和聯結器部分，以瞭解目前支援的內容。

>[!NOTE]
>
>同事聊天是Adobe CX Enterprise Coworker的一個模組。 其他兩個模組則延伸了相同基礎：同事行銷活動（從一場交談中站起來並啟動一個完整的行銷活動）和同事專案（端對端、多團隊工作流程的永遠線上工作區）。 本頁涵蓋「同事聊天」。

## AI助理的演變

如果您已使用AI Assistant和Adobe Experience Platform Agent Orchestrator，同事聊天是下一個程式。 AI助理正逐漸變成同事聊天。 您現在可以在AI Assistant中叫用Adobe專門建置的代理程式執行的所有操作（產品知識、操作和資料見解、對話式體驗）都將隨時可用。 「同事聊天」由同事組成要素（企業工具、技能、治理和記憶體）作為後盾，因此相同的交談現在可以超越接聽，實際完成端對端的工作。

## 聊天體驗

* **豐富的交談結果：**&#x200B;圖表、表格和互動式人工因素會在您工作的位置內嵌呈現。 您可以上傳影像供Co-worker使用，並在交談中預覽PDF，無需在工具之間切換。
* **它會顯示其工作：**&#x200B;當同事聊天進行一項任務時，您可以觀看其原因和進度（載入適當的技能、檢查您的資料模型、執行合規性檢查、尋找重疊），因此您永遠知道它在做什麼以及為什麼。
* **長而複雜的工作階段：**&#x200B;同事聊天會維持延伸、多步驟的工作階段，並在這些工作階段之間保留內容，因此您可以在一個位置從頭到尾處理問題。
* **建議和後續提示：**&#x200B;同事聊天會建議後續步驟，因此您不必猜測要問什麼。
* **交談記錄：**&#x200B;已儲存過去的交談，因此您可以返回先前的工作、從中斷的地方取回並重複使用同事交談產生的內容。
* **內建的意見反應：**&#x200B;將任何回應評為豎起或豎下大拇指，告訴同事聊天什麼有效什麼無效；您的意見反應有助於隨著時間改善體驗。

## 建置區塊

同事聊天由同事建置區塊提供支援。 下列建置區塊目前可供使用。

* **企業環境：**&#x200B;將目標轉換為已完成工作的引擎。 它會執行連續、自我修正的回圈（原因、選取技能、執行、驗證、重複）、從錯誤中復原並並行工作，直到完成工作為止，而不僅僅是嘗試完成。
* **技能：**&#x200B;可重複使用的教戰手冊，使用Markdown語言輕鬆完成每項工作。 「同事聊天」提供現今最常見客戶體驗工作的相關技能，目標是涵蓋所有Adobe CX Enterprise應用程式隨著時間流逝的工作。
* **MCP聯結器：**&#x200B;已控管存取，可跨Adobe和協力廠商系統運作，並提供現成的聯結器以及您自己的選項。
* **治理：**&#x200B;核准閘門、從您的Adobe組織繼承的許可權、執行動作前執行的檢查，以及完整的稽核軌跡。
* **記憶體：**&#x200B;同事聊天會學習您在不同工作階段中的喜好設定、決定和更正內容，範圍從整個組織的規則到您的個人喜好設定，因此當您使用聊天工具時，其內容會更清晰。
