# 透過同事聊天建立資產來源入口網站

瞭解如何與同事設定適用於AEM Assets的Adobe Asset Sourcing入口網站，並授予供應商特定範圍的入口網站存取權。 內嵌資產時，會在Adobe Experience Manager Assets中對應自訂中繼資料欄位，並自動同步中繼資料。
