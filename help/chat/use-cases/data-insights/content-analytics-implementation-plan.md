# 規劃Adobe Content Analytics實施

瞭解CX Enterprise Coworker中的ACA實作指南如何建立量身打造的Adobe Content Analytics實作計畫，無論是將Content Analytics新增至現有的Customer Journey Analytics (CJA)部署，還是從獨立設定開始。

## 您將瞭解的內容

- Co-worker如何使用引導式探索程式來擷取授權、管道、SDK、行為資料、身分拼接、隱私權和報表需求。
- 指南如何排列實作階段、指派擁有者、識別相依性以及估計關鍵路徑時間表。
- 計畫與現有CJA部署和獨立Content Analytics實作有何不同。
- 如何追蹤進度、修訂假設，以及將實作任務匯出為CSV和Jira。

>[!VIDEO](https://video.tv.adobe.com/v/3508620/?learn=on&enablevpops)

## 將Content Analytics新增至現有的CJA部署

第一個逐步解說會從已透過Web和行動使用CJA的組織開始。 Adobe Tags和Web SDK支援網站、Mobile SDK支援應用程式，而且CJA連線、資料檢視和資料流已經存在。

根據答案，Co-worker會產生一份計畫，說明成功實作所需的所有工作以及實作團隊控制之外的相依性。

## 從獨立Content Analytics開始

第二個逐步解說會從沒有現有CJA部署開始。

同事會產生一項計畫，其中包括與Adobe帳戶團隊確認行為資料需求，以及為網站行為資料建立結構描述和資料集。 引導式精靈會建立CJA連線和資料檢視。

## 追蹤進度並匯出計畫

影片示範互動式單頁追蹤器，將步驟標示為完成、重新開啟或延遲。 當實作詳細資訊變更並重新產生檔案時，同事可以更新計畫。

本指南支援其他匯出格式，包括：

- **CSV：**&#x200B;實作步驟，包含階段、付出、擁有者、相依性和狀態。
- **Jira：**&#x200B;待處理專案就緒的結構，階段為史詩，步驟為劇本，包括優先順序和劇本點。

## 主要外賣

Adobe Co-worker中的ACA實作指南可將實作需求轉換為循序且可執行的計畫。 透過儘早適應您的開始環境並呈現安全性、隱私權和組態相依性，這有助於團隊協調和追蹤Adobe Content Analytics的轉出。
